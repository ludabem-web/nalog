# Налоговый навигатор

Автономный веб-калькулятор сравнения налоговых режимов для ИП и ООО по формулам предоставленного ТЗ.

## Запуск

Откройте `index.html` в современном браузере. Установка зависимостей и интернет не нужны.

## Возможности

- автоматическое сравнение 10 сценариев;
- рейтинг по чистой прибыли и сравнительная диаграмма;
- подробный P&L и объяснение расчёта;
- экспорт результатов в CSV;
- скрытые редактируемые параметры законодательства;
- локальное сохранение настроек в браузере.

## Допущения ТЗ

Расчёт следует формулам ТЗ буквально. В частности, взносы за работников и взносы ИП за себя не вычитаются из операционной прибыли: они используются только для уменьшения УСН «Доходы». Ограничения применимости налоговых режимов не проверяются.
